LetterPixels_2sigmoid - реализация двухслойной нейросети (перцептрон) для распознавания букв. Без каких-либо библиотек, кроме numpy. Датасет нарисован собственноручно в Paint: по 6 картинок для букв A, B, C, D, 4 картинки для обучения, 2 - для теста (изображения прикреплены в ноутбуке, в первой же ячейке, но на гитхабе выглядят мелко).

RBF - реализация сети с радиальными базисными функциями, тоже только numpy. Датасет: выборка - набор точек от -20 до 20 с шагом 0.25, ответы (3 набора) - полиномиальная функция, парабола и сигмоида. С помощью РБФ аппроксимируем эти функции.

SOFM - реализация самоорганизующейся карты Кохонена, только numpy. 1) представление выборки точек случайных цветов, 2) представление параболы, 3) снова представление цветов, но диапазон цветов - только ч/б, 4) представление ирисов с помощью карты Кохонена

XOR_TensorFlow - решение задачи XOR без использования Keras, только TensorFlow, с реализацией собственных классов dense-слоя, двухслойной модели с наследованием от tf.Module и использованием градиентной ленты tf.GradientTape.

LinReg - просто знакомство с Keras, нейросеть с линейными слоями на игрушечном датасете california housing

myCNN - CNN с Keras

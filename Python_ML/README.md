LetterPixels_2sigmoid - реализация двухслойной нейросети (перцептрон) для распознавания букв. Без каких-либо библиотек, кроме numpy. Датасет нарисован собственноручно в Paint: по 6 картинок для букв A, B, C, D, 5 для обучения, 1 - для теста (изображения прикреплены в ноутбуке).

RBF - реализация сети с радиальными базисными функциями, тоже только numpy. Датасет: выборка - набор точек от -20 до 20 с шагом 0.25, ответы (3 набора) - полиномиальная функция, парабола и сигмоида. С помощью РБФ аппроксимируем эти функции.

SOFM - реализация самоорганизующейся карты Кохонена, только numpy. 1) представление выборки точек случайных цветов, 2) представление параболы, 3) снова представление цветов, но диапазон цветов - только ч/б, 4) представление ирисов с помощью карты Кохонена

BidirectionalNet - реализация двунаправленной ассоциативной сети, только numpy. Датасет из картинок 3-х цифр размером 5x3. Сеть запоминает пары картинка-массив (матрица 5x3-массив 3). Если подана зашумленная картинка, то на выходе ассоциация (вектор размера 3), и наоборот. Но у меня картинка перед подачей разглаживается в вектор размера 15.

Hopfield - реализация сети Хопфилда, только numpy. Датасет из 2-х картинок собаки и кошки размера 10x10 (разглаженных в вектор размера 100). Сеть их также запоминает, и если на вход подать зашумленную картинку (у меня разглаженную, конечно), то вернёт восстановленную картинку.

XOR_TensorFlow - решение задачи XOR без использования Keras, только TENSORFLOW, с реализацией собственных классов dense-слоя, двухслойной модели с наследованием от tf.Module и использованием градиентной ленты tf.GradientTape.

LinReg - просто знакомство с Keras, нейросеть с линейными слоями на игрушечном датасете california housing

myCNN - CNN с Keras
